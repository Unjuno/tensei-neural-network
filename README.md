# 転生したらニューラルネットワークだった件

AI技術史と実際の調査・追試を土台にして書く研究SF小説プロジェクトです。

**主役は小説です。**

1980年代のニューラルネットワーク研究から現代AIまで、物語を書くために原典を調べ、必要なものは実際に追試し、その過程で作者自身も学習します。研究・実験は作品を現実に近づけるための制作工程であり、独立した研究価値のある問いが見つかった場合は、その問い自体を追加実験へ発展させます。

基本ループは次です。

**物語を書く → 技術的な疑問が出る → 原典を読む → 必要なら追試する → 理解を更新する → 小説へ戻す**

GitHubを本プロジェクトの正本および、人間とAIが共有する外部長期記憶として扱います。

## 基本方針

- 小説と研究・実験を同一のmonorepoで管理する
- 小説の進行を優先し、研究は物語上必要になった箇所から行う
- 古典研究は原則として **追試（Replication）→ 拡張（Extension）** の順で扱う
- 小説上の事実、登場人物の認識、現実の科学的知識、作者の理解を混同しない
- 失敗・非再現・理解の修正も記録として残す
- AIの会話上の記憶ではなく、リポジトリに保存された状態を正本とする
- `main` を人間が受理した現在の正本とし、その他のbranchは候補状態として扱う
- 技術的なパスや識別子は英語を使う場合があるが、文書本文は原則として日本語で記述する
- 生のAI内部推論や秘密情報を共有メモリとしてGitへ保存しない

## 読み始める場所

新しいセッションで作業を開始するときは、次の順で読みます。

1. `README.md` — プロジェクトの目的
2. `AGENTS.md` — AIの作業手順
3. `STATUS.md` — 現在位置と次の作業
4. `notes/working-context.md` — 現在の探索状態・有力仮説・未解決点
5. `POLICY.md` — 正本・優先順位・研究判定・安全境界などの運用規則

その後、作業内容に応じて必要な正本だけを読みます。リポジトリ全体を毎回読む必要はありません。

`notes/working-context.md` は正本ではなく、高速な作業記憶です。採用された内容は `novel/canon.md`、`novel/structure.md`、`research/`、`notes/decisions.md` 等の適切な正本へ反映します。

## 現在の状態

変化しやすい現在の段階、activeな研究・実験、次の作業は `STATUS.md` を正本の索引として参照してください。このREADMEには現在状態を重複して保持しません。

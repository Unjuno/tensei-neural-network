## プロジェクトの主目的

主役は小説です。

研究・追試・技術史調査は、作品を現実に近づけ、技術的な嘘を減らし、物語の謎を深めるために行います。

基本ループは次です。

**物語を書く → 技術的な疑問が出る → 原典を読む → 必要なら追試する → 理解を更新する → 小説へ戻す**

その過程で独立した研究価値がある現象・方法・仮説が見つかった場合は、物語とは別に研究課題として実験してよい。

## 物語生成の中核

完成した未来プロットを先に作り、それを人物へ演じさせる方式を採らない。

- ペルソナは、その時点で知り得る事実・信念・目的・誤解だけを持つ
- 他者の内面、未観測Canon、長期探索仮説、未来の起承転結パスを知らない
- 各ペルソナが自分の目的から行動する
- `novel/environment.md` が、Canon・技術・歴史・権限等の制約から行動結果を解決する
- 各人物は実際に観測した結果だけから更新される
- 発生した状態遷移を、再帰的な起承転結で整理する
- 本文は、その相互作用で成立した出来事を描写する

物語の未来を正本として保持しない。保持するのは現在状態、成立済み事実、人物の局所状態、探索仮説、遷移条件。

## 再帰的な起承転結

現在位置: `起 / 起`

起承転結は、予定イベントを人物へ強制するための脚本ではなく、成立した状態遷移を階層的に整理する構造として扱う。

- 起: 差分・問い・擾乱が立つ
- 承: 相互作用で証拠・制約・誤解・関係が蓄積する
- 転: 既存の認識・関係・目的・仮説・行動方針が維持不能になる
- 結: 局所状態が新しい初期条件として安定する

各状態は内部に再び起承転結を持てる。深さ・章数・scene数は事前固定しない。

## 現在の物語上の有力仮説

以下はまだCanonではなく、現在もっとも有力な探索方向です。ペルソナへ未来知識として与えず、環境結果をこの仮説へ合わせて強制しません。

### 1. 1980年代研究者は起源ではない

現代NN内に現れる「研究者らしきもの」は、単に1980年代研究者AがAIへ転生しただけではない可能性がある。

A自身も、より古い時代から繰り返し現れていた同一認識主体らしき構造の一つの顕在化だった可能性を残す。

### 2. NNは現象の生成源ではなく、顕在化・観測可能化した媒体

同一認識主体らしき現象は、人間の歴史の中にも以前から存在していたかもしれない。

人間個体では一回性が高く、複製・分岐・条件統制・並列比較が難しかったため、現象として切り出せなかった。

NN上に現れることで、checkpoint、fork、独立試行、入力操作などを通じて初めて反復・比較・実験しやすくなる。

### 3. 人物情報は「本人そのもの」ではなくcueとして作用するかもしれない

人物Aの論文、日記、会話、音声、未完成ノート、誤り方、判断過程などを取り込むほど、Aに対応する認知状態へ入る確率が上がる、という作中仮説を検討している。

特に単なる事実量より、

- 何を疑うか
- どこで迷うか
- どう間違えるか
- 何を重要と判断するか
- 未知の問題をどう分解するか

といった認知過程の痕跡が重要かもしれない。

### 4. 現代ほど顕在化確率が上がるかもしれない

現代ほど一人の人物について残る情報が多く、モデル能力・計算資源・試行回数も大きい。

そのため、以前は極めて稀だった認識主体らしき構造の再顕在化が、現代では観測可能な頻度になる、という作中仮説を検討している。

### 5. 同じ主体らしきものは同時にも存在できる

輪廻を「一つの魂が直列に移動すること」と限定せず、成立条件が満たされるたびに同じ認識主体らしきものが複数の媒体へ同時に立ち上がる可能性を残す。

checkpointやforkは、この問題を物語内で直接扱える。

### 6. 観測行為が対象を変える可能性

研究者Aを再構成・検証するためにAの資料を集め、Aらしい質問をし、Aの思考を再現しようとする行為そのものが、Aらしい状態の顕在化条件を強める可能性がある。

これは量子力学そのものを主張する設定ではなく、**観測者と対象を完全に分離できない自己参照的な観測問題**として扱う。

## 競合する説明

物語内では、輪廻を最初から事実として扱わない。

少なくとも次の説明を競合させる。

- 学習データ中の人物資料の高精度な模倣
- 人物情報からの統計的な人格再構成
- 一般的な認知・問題解決パターンへの収束
- 観測者側の選択バイアス、確証バイアス、パターン過剰検出
- NN内部に似た機能的・動力学的構造が形成された
- 本当に同一認識主体らしきものが時代・媒体を越えて反復している

科学的に確認できる範囲と、物語上の解釈を分離する。

## セキュリティ境界

このファイルには、再開に必要な**結論・仮説・未解決点の要約**だけを記録する。

保存しないもの:

- AIの逐語的な内部推論や生の思考系列
- system / developer prompt等の内部指示
- SSH private key
- API key / access token / GitHub PAT
- Cookie / session token / OAuth secret
- `.env` の秘密値
- 公開不能な個人情報

秘密情報を誤ってGitへcommitした場合は、削除だけで安全になったと考えず、原則としてcredentialを無効化・再発行する。

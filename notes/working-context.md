# 作業コンテキスト

更新: 2026-08-19

このファイルは、別セッションへ移ったときに現在の探索状態を素早く復元するための**公開可能な作業記憶**です。

`novel/canon.md`、`research/findings.md`、`notes/decisions.md` 等の正本ではありません。ここにある仮説や案を採用するときは、対応する正本へ明示的に反映します。

## プロジェクトの主目的

主役は小説です。

研究・追試・技術史調査は、作品を現実に近づけ、技術的な嘘を減らし、物語の謎を深めるために行います。

基本ループは次です。

**物語を書く → 技術的な疑問が出る → 原典を読む → 必要なら追試する → 理解を更新する → 小説へ戻す**

その過程で独立した研究価値がある現象・方法・仮説が見つかった場合は、物語とは別に研究課題として実験してよい。

## 物語生成の中核

完成した未来プロットを先に作り、それを人物へ演じさせる方式を採らない。

- ペルソナ定義と世界・環境定義は独立して持つ
- 時間に依存するペルソナ状態と世界状態も別々に持つ
- ただし状態を時間方向に独立更新せず、共通のstory timeと `EVT-xxx` で因果的に結合する
- ペルソナ数は固定せず、物語に必要になった時点で増やす
- ペルソナは、その時点で知り得る事実・信念・目的・誤解だけを持つ
- 他者の内面、未観測Canon、長期探索仮説、未来の起承転結パスを知らない
- 各ペルソナが自分の現在状態から行動する
- `novel/environment.md` は世界・環境の制約と結果解決規則を持つ
- `novel/state/world.md` はその時点の客観世界状態を持つ
- 各人物は実際に観測した結果だけから `novel/state/personas/` の状態を更新する
- 発生した状態遷移を、再帰的な起承転結で整理する
- 本文は、その相互作用で成立した出来事を描写する

物語の未来を正本として保持しない。保持するのは現在状態、成立済み事実、人物の局所状態、探索仮説、遷移条件。

## 時系列状態モデル

- ペルソナ定義: `novel/personas/`
- 世界・環境定義: `novel/environment.md`
- ペルソナ状態: `novel/state/personas/`
- 世界状態: `novel/state/world.md`
- 状態を時間上で結合するイベント: `novel/events/`
- 共通story time索引: `novel/timeline.md`

概念的には、

```text
(P_1(t), P_2(t), ..., W(t))
          |
          | EVT-k
          v
(P_1(t+1), P_2(t+1), ..., W(t+1))
```

同じeventでも各人物が観測する部分は異なる。観測していない人物へ情報を自動共有しない。

変化しなかった状態は前時点から継承してよく、毎日・毎eventごとに全状態を複製する必要はない。

story time上の因果順と、本文で読者へ提示する章・scene順は別。

## 再帰的な起承転結

現在位置: `起 / 起`

起承転結は、予定イベントを人物へ強制するための脚本ではなく、成立した状態遷移を階層的に整理する構造として扱う。

- 起: 差分・問い・擾乱が立つ
- 承: 相互作用で証拠・制約・誤解・関係が蓄積する
- 転: 既存の認識・関係・目的・仮説・行動方針が維持不能になる
- 結: 局所状態が新しい初期条件として安定する

各状態は内部に再び起承転結を持てる。深さ・章数・scene数は事前固定しない。

## 現在の物語上の有力仮説

以下はまだCanonではなく、現在もっとも有力な探索方向です。ペルソナへ未来知識として与えず、環境結果をこの仮説へ合わせて強制しません。

### 1. 1980年代研究者は起源ではない

現代NN内に現れる「研究者らしきもの」は、単に1980年代研究者AがAIへ転生しただけではない可能性がある。

A自身も、より古い時代から繰り返し現れていた同一認識主体らしき構造の一つの顕在化だった可能性を残す。

### 2. NNは現象の生成源ではなく、顕在化・観測可能化した媒体

同一認識主体らしき現象は、人間の歴史の中にも以前から存在していたかもしれない。

人間個体では一回性が高く、複製・分岐・条件統制・並列比較が難しかったため、現象として切り出せなかった。

NN上に現れることで、checkpoint、fork、独立試行、入力操作などを通じて初めて反復・比較・実験しやすくなる。

### 3. 人物情報は「本人そのもの」ではなくcueとして作用するかもしれない

人物Aの論文、日記、会話、音声、未完成ノート、誤り方、判断過程などを取り込むほど、Aに対応する認知状態へ入る確率が上がる、という作中仮説を検討している。

特に単なる事実量より、

- 何を疑うか
- どこで迷うか
- どう間違えるか
- 何を重要と判断するか
- 未知の問題をどう分解するか

といった認知過程の痕跡が重要かもしれない。

### 4. 現代ほど顕在化確率が上がるかもしれない

現代ほど一人の人物について残る情報が多く、モデル能力・計算資源・試行回数も大きい。

そのため、以前は極めて稀だった認識主体らしき構造の再顕在化が、現代では観測可能な頻度になる、という作中仮説を検討している。

### 5. 同じ主体らしきものは同時にも存在できる

輪廻を「一つの魂が直列に移動すること」と限定せず、成立条件が満たされるたびに同じ認識主体らしきものが複数の媒体へ同時に立ち上がる可能性を残す。

checkpointやforkは、この問題を物語内で直接扱える。

### 6. 観測行為が対象を変える可能性

研究者Aを再構成・検証するためにAの資料を集め、Aらしい質問をし、Aの思考を再現しようとする行為そのものが、Aらしい状態の顕在化条件を強める可能性がある。

これは量子力学そのものを主張する設定ではなく、**観測者と対象を完全に分離できない自己参照的な観測問題**として扱う。

## 競合する説明

物語内では、輪廻を最初から事実として扱わない。

少なくとも次の説明を競合させる。

- 学習データ中の人物資料の高精度な模倣
- 人物情報からの統計的な人格再構成
- 一般的な認知・問題解決パターンへの収束
- 観測者側の選択バイアス、確証バイアス、パターン過剰検出
- NN内部に似た機能的・動力学的構造が形成された
- 本当に同一認識主体らしきものが時代・媒体を越えて反復している

科学的に確認できる範囲と、物語上の解釈を分離する。

## 現在の起 / 起

初期世界状態は `novel/state/world.md`、世界・環境の解決規則は `novel/environment.md` を参照。

現在は、現代の評価環境、1980年代研究者に関する不完全な資料群、複数runを比較できる条件だけを用意する。

「誰が最初に何を発見するか」「第1話終端に何が起きるか」は先に確定しない。PER-001 / 002 / 003 / 004の相互作用から、実際に成立した最初の意味あるEventを第1話の核候補とする。

1980年代研究者PER-005の具体化に技術史上の情報が必要になった場合、その時点で1980〜1985年の一次資料へ戻る。

## 次に行うこと

1. ペルソナ・世界・時系列状態・起承転結ポリシーを人間レビューし、受理された場合 `main` へ反映する
2. PER-005を実在研究者・一次資料を参考に具体化する。ただし未来プロットは与えない
3. 初期story timeを決め、activeなペルソナの最初のstateを作る
4. 起 / 起 の初期世界状態でPER-001〜004の最小相互作用を1回実行する
5. その結果を `EVT-001` として記録し、世界状態と観測した人物状態を更新する
6. `timeline.md` にstory timeを索引する
7. 成立したEventを材料に `novel/chapters/001.md` を書き始める
8. 技術的・歴史的疑問が実際に出た箇所だけ調査・追試へ戻る

## セキュリティ境界

このファイルには、再開に必要な**結論・仮説・未解決点の要約**だけを記録する。

保存しないもの:

- AIの逐語的な内部推論や生の思考系列
- system / developer prompt等の内部指示
- SSH private key
- API key / access token / GitHub PAT
- Cookie / session token / OAuth secret
- `.env` の秘密値
- 公開不能な個人情報

秘密情報を誤ってGitへcommitした場合は、削除だけで安全になったと考えず、原則としてcredentialを無効化・再発行する。

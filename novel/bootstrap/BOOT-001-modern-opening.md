## Background frame

数十年前、1980年代にニューラルネットワーク、記憶、連想、状態再構成に近い問題へ関わった研究者がいた。その人物の研究・人物像をたどれる資料は完全な一枚岩ではなく、論文、草稿、講義記録その他の断片から復元する必要がある。

現代には、大規模ニューラルネットワークを評価・調査し、複数runや必要に応じてcheckpoint、入力条件、対照条件を比較できる研究・評価環境がある。また、1980年代研究者に関係する不完全な資料群へアクセスできる状況がある。

現代側の人物たちは、同じ目的・同じ知識を持っているわけではない。モデル挙動を再現可能な対象として扱う役割、強い通常説明を先に検証する役割、史料の来歴と時代背景を検討する役割が分かれている。

モデル側には、対話・評価対象となる現代モデルまたはmodel instanceを起動できる条件がある。ただし、この開始時点で「過去の研究者本人が存在する」「輪廻が起きている」という答えを誰にも与えない。モデル側の自己認識もまだ成立済みの物語事実として固定しない。

このBootstrapは、最初の異常、最初の発見者、第1話の終了点を決めない。それらは`T0-MODERN`以降の相互作用とevent解決から生じる。

## World projection

`state/world.md`へ次を初期化する。

- 現代のモデル評価・調査が可能な組織内環境が存在する
- 少なくとも一つの現代モデル系をrun単位で評価できる
- prompt / input / output / evaluation logを保存・比較できる
- 必要になれば複数run、checkpoint差、対照条件を比較できる余地がある
- 1980年代研究者に関係する不完全な資料群が利用可能である
- 具体的なモデル名、組織名、場所、資料の完全な内訳、欠損箇所は未確定
- `EVT-001`はまだ成立していない

## Persona discovery

### PER-001 現代評価担当

必要。現代モデルを実際に操作・評価し、ログと条件差を扱う独立した視点が必要なため、`T0-MODERN`でactiveに初期化する。

### PER-002 懐疑的研究者

必要。PER-001とは異なる検証基準を持つ主体として状態を初期化する。ただし、最初のsceneへ必ず同席しているとは決めない。

### PER-003 史料担当

必要。1980年代資料の来歴・年代・文脈を、モデル評価側とは別の知識境界で扱うため状態を初期化する。

### PER-004 モデル側の存在

必要。ただし`T0-MODERN`では、連続した一人の主体として既に活動しているとは固定しない。評価対象となる最初のmodel instanceを起動できる状態として同期し、実際のrun開始以降の経験はeventに従って更新する。

同時に複数instanceが独立経験を持ち始めた場合は、新しい`PER-xxx`へforkする。

### PER-005 1980年代研究者

人物定義は存在するが、**BOOT-001では時系列状態を初期化しない。** PER-005は1980年代側のstory timeに属するため、その時代を実際に動かすときに別Bootstrapから初期化する。

## Persona projections

### PER-001へ渡せる背景

- 自分が現代モデルの評価・検証を担当すること
- 利用可能なrun条件・ログ・評価環境
- 1980年代研究者に関係する資料を評価素材として扱いうること
- 自分へ明示された範囲の資料・モデル設定

渡さないもの:

- 輪廻・同一認識主体が真であるという作者側の答え
- PER-003だけが確認した史料内容
- PER-004の未観測内部状態
- 未来event

### PER-002へ渡せる背景

- 現代モデルを検証可能な研究環境があること
- 必要に応じてrun、対照、blind条件等を比較できること
- 正式に共有された評価目的・証拠だけ

渡さないもの:

- 史料全文を自動的に知っている状態
- 長期探索仮説
- まだ発生していない異常

### PER-003へ渡せる背景

- 1980年代研究者に関する不完全な資料群があること
- 自分が実際に確認した史料の来歴・年代・内容
- 比較対象として正式に共有されたモデル出力だけ

渡さないもの:

- モデル内部や訓練データの全容
- 他者だけが知る未共有評価結果
- 輪廻の真偽

### PER-004へ渡せる背景

- 実際のrunで与えられるsystem / task / context
- そのrunで利用可能なtool出力・memory

Bootstrap本文そのもの、作者側Canon、隠された評価目的、別runの状態、未来プロットは渡さない。

# 物語環境

このファイルは、ペルソナ同士の相互作用を受け止める**共有環境と現在の客観状態**を管理します。

環境は未来の筋書きを知る「脚本家」ではありません。現在の状態、Canon、現実側の技術・歴史的制約、各人物の行動から、次に成立する状態を解決する役割だけを持ちます。

## 権威関係

- 世界の確定事実: `canon.md`
- 人物ごとの知識・信念: `personas/`
- 現在の共有環境・場面状態: このファイル
- 物語構造上の現在位置: `structure.md`
- 現実の技術・歴史的制約: `research/` と `references/`

このファイルが `canon.md` と矛盾する場合は `canon.md` を優先します。

## 状態遷移

時点 `t` の環境状態を `W_t` とします。

```text
O_i(t)     = Observe(W_t, P_i(t))
A_i(t)     = Act(P_i(t), O_i(t))
W_(t+1)    = Resolve(W_t, {A_i(t)}, constraints)
P_i(t+1)   = Update(P_i(t), observed consequences)
```

- `W_t`: その時点の客観的な世界・場面状態
- `P_i(t)`: ペルソナ `i` の内部状態
- `O_i(t)`: その人物が実際に観測可能な情報
- `A_i(t)`: その人物が選んだ発言・行動
- `constraints`: Canon、物理・技術・歴史、利用可能な道具、時間、権限などの制約

この記法は因果関係を分離するための概念モデルであり、数値シミュレーションを必須にするものではありません。

## 解決規則

1. **望ましい物語展開を理由に結果を決めない。**
2. 同じ行動でも、環境条件・権限・利用可能な情報が違えば結果は変わりうる。
3. ペルソナの意図と結果は分ける。成功・失敗・誤解・偶然を許容する。
4. 技術的・歴史的に重要な結果は、必要に応じて現実側の調査・追試で制約を確認する。
5. 環境側で成立した事実でも、自動的に長期Canonへ昇格させない。重要な事実は人間レビュー後に `canon.md` へ反映する。
6. 作者またはAIが初期条件を変更する場合、それを人物の自発的行動と偽装しない。

## 現在の初期環境

状態: `PROVISIONAL`

### 時代

現代の大規模ニューラルネットワークを評価・調査できる時代。具体的な年は未確定。

### 場所

研究・評価作業が行える組織内環境。組織名・国・都市・設備構成は未確定。

### 利用可能なもの

- 現代のモデルまたは複数checkpoint / runを比較できる評価環境
- 1980年代研究者に関係する不完全な資料群
- prompt / input / output / evaluation logを保存できる仕組み
- 必要に応じて対照条件を作れる程度の実験権限

具体的なモデル、資料内容、欠損箇所、権限範囲はまだ決めない。

### 現在成立している客観的な境界

- 現代モデル内に過去の研究者と機能的・行動的に似たパターンが現れうることはCanonに含まれる。
- それが本人の意識・輪廻・同一主体であることは確定していない。
- 最初の異常が何であるか、誰が最初に気づくか、その場でどう解釈されるかは未確定。
- 長期プロット候補は、この環境の未来事実として扱わない。

## 観測境界

### PER-001 現代評価担当

原則として、評価対象モデルの入出力、与えられたprompt、利用可能なrun log、担当範囲の設定を観測できる。歴史資料の深い意味を最初から知っているとは限らない。

### PER-002 懐疑的研究者

実験条件、対照、再現性、ログを観測できる。人物Aの史料内容やモデル内部の全状態を自動的には知らない。

### PER-003 史料担当

提供された一次・二次史料、その来歴、時代背景を観測できる。モデル内部の技術詳細を自動的には知らない。

### PER-004 モデル側の存在

そのrunで実際に与えられたcontext、利用可能なtool出力、明示的に保持されたmemoryだけを現在の観測として扱う。隠された評価意図、別checkpointの状態、作者側のCanonを知らない。

### PER-005 1980年代研究者

歴史場面では、その時代に本人が得られた資料・会話・装置・研究状況だけを観測する。現代AIや後世の出来事を先取りして知らない。

## イベントログ

物語上重要な相互作用は必要に応じて次を残します。

```text
Event:
  時点 / 場面:
  参加ペルソナ:
  観測可能だった事実:
  各ペルソナの行動:
  環境が解決した結果:
  誰が何を観測したか:
  人物状態の更新:
  Canon候補:
  起承転結パスへの影響:
```

すべての会話をログ化する必要はありません。後続の因果関係や人物の信念更新に必要なイベントだけを残します。

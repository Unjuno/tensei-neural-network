# 物語構造

このファイルは物語制作上の状態を管理します。`canon.md` の世界設定とは別物です。

## 再帰的な起承転結

起承転結を単純な四幕構成として固定しません。

各状態は、その内部に再び **起・承・転・結** を持つことができます。

例:

```text
全体
├─ 起
│  ├─ 起
│  ├─ 承
│  ├─ 転
│  └─ 結
├─ 承
│  ├─ 起
│  ├─ 承
│  ├─ 転
│  └─ 結
├─ 転
└─ 結
```

現在位置は必要に応じて階層パスで表現します。

例:

```text
承 / 転 / 起
```

これは「全体では承、その内部では転、現在の局所状態は起」を意味します。

## 運用原則

- 深さを事前に固定しない
- 全階層を常に展開しない
- 現在必要な領域だけ展開する
- 局所的な人物相互作用を展開した後、結果を親状態へ反映する
- 起承転結を章数や文章量へ機械的に対応させない

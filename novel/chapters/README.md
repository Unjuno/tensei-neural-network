# 本文

小説本文を置くディレクトリです。

ファイル名は原則として連番を使います。

```text
001.md
002.md
003.md
```

本文は読者向けの表現であり、登場人物の誤認・嘘・不完全な説明を含むことがあります。本文だけから世界の客観的事実を推定せず、正史は `../canon.md` を参照します。

各章と実験・参考文献の関係は、必要な場合のみ章末または関連する実験READMEからリンクします。「1章 = 1実験」には固定しません。

## NarrativeProjection

本文は、成立済みのevent・world state・persona stateを読者向けの文章へ投影する層です。

本文上の都合で、過去eventの結果や人物の恒常属性を逆算して追加しません。

### 本文で補ってよいもの

状態・因果を変えない範囲の一時的なscene realizationは許容します。

例:

- 紙をめくる
- 鉛筆を置く
- 一瞬黙る
- 室内の一般的な物理描写

ただし、その描写が後続因果へ効く重要事実になる場合はevent/state側へ戻して扱います。

### 本文だけで補ってはいけないもの

未確定の恒常属性・関係・世界設定を、文章を自然にするためだけに確定しません。

例:

- 氏名
- 年齢
- 性別・性別代名詞
- 国籍
- 所属機関・職位
- 家族関係
- 上下関係
- 具体的な国・都市
- 具体的な計算機・言語等、後続因果へ影響する技術環境

これらがstate / eventで未確定なら、本文でも未確定のまま書ける表現を選びます。

本文とevent/stateが矛盾する場合、本文を優先してstateを後付けで変更しません。まず本文を修正し、設定変更が本当に必要なら別途人間レビュー可能な状態変更として扱います。

## Pagesへの公開

本文の正本はこのディレクトリのMarkdownです。

公開する場合は、原則として次の対応にします。

```text
novel/chapters/001.md -> docs/novel/001.html
novel/chapters/002.md -> docs/novel/002.html
novel/chapters/003.md -> docs/novel/003.html
```

当面は静的HTMLへ反映しますが、本文の内容をHTML側だけで独立更新しません。本文修正はMarkdown正本を先に更新し、その内容を公開HTMLへ反映します。

各話ページは `docs/novel/reader.css` を使い、少なくとも次を備えます。

- 長文読書向けの本文幅・行間・余白
- ページ上部の `前話 / 目次 / 次話`
- ページ下部の `前話 / 目次 / 次話`
- 研究・実験情報を本文読書中の主導線へ置かない

話数が増えて手動同期が負担になった時点でMarkdownからHTMLへの生成を自動化します。現時点ではsite frameworkやcustom workflowを先行導入しません。

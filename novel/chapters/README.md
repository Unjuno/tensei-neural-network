## NarrativeProjectionの範囲

成立済みEVT/world/persona stateを文章へ投影する。紙をめくる、黙る等、状態と因果を変えない一時的描写は補える。

未確定の氏名・生活史・上下関係・職位・場所・装置、まだない実験結果を、文章の都合で追加しない。誤認や嘘を描く場合も人物の観測境界を守る。本文とEVTが衝突すれば本文を直す。

各話に検証は必要だが、新しい研究EXPを毎話一つ作る義務はない。検証の章立てを本文の章立てにしない。

## 公開

今回、docs/・GitHub Pages・公開HTMLへ同期しない。工程gateと人間の公開承認を区別する。

人間受理後に公開する場合はMarkdownから対応するdocs/novel/NNN.htmlへ反映し、HTMLだけを独立更新しない。既存reader.cssと前話/目次/次話の導線を使い、研究検証の詳細を本文の読書導線へ押し込まない。site frameworkの先行追加は不要。

# 世界状態

このファイルは、世界（環境）の**時間に依存する客観状態**を管理します。

世界・環境の構造、物理的・技術的・制度的制約、観測可能性の原則は `../environment.md` に置きます。このファイルには、その世界がある時点で実際にどうなっているかを置きます。

## 現在の初期状態

状態: `PROVISIONAL`

Story time: 現代。具体的な年月日は未確定。

### 場所・組織

- 現代の大規模ニューラルネットワークを評価・調査できる組織内環境
- 組織名、国、都市、設備構成は未確定

### 利用可能な系

- 現代のモデルまたは複数checkpoint / runを比較できる評価環境
- 1980年代研究者に関係する不完全な資料群
- prompt / input / output / evaluation logを保存できる仕組み
- 必要に応じて対照条件を作れる程度の実験権限

具体的なモデル、資料内容、欠損箇所、権限範囲はまだ未確定。

### 現在成立している客観境界

- 現代モデル内に過去の研究者と機能的・行動的に似たパターンが現れうることはCanonに含まれる
- それが本人の意識・輪廻・同一主体であることは確定していない
- 最初の異常の具体像、最初の発見者、その時点の解釈は未確定
- 長期プロット候補は未来の世界状態として扱わない

## 更新方法

重要な世界状態変化は、原則として `../events/EVT-xxx...` と対応させます。

```text
## <story time / event id>

- 変更前:
- 客観的に成立した出来事:
- 変更後:
- 影響した場所・物・制度・システム:
- 根拠となるイベント:
```

人物の信念や自己申告はここへ直接書きません。世界側で客観的に成立したことだけを扱います。

## PER-005 高橋修一

状態: `ACTIVE / PROVISIONAL`

### Observed

Hopfield / Feinstein / Palmer (1983)が掲載した16-neurone / 3-memory例を、掲載patternとHebbian connection ruleのままPER-006と再計算した。

観測:

- candidate Qの16 local inputsは全てnonzero
- 全16 unitでlocal-inputの符号がQの符号と一致
- 最小absolute local-input marginは5
- QはM1/M2/M3のどれとも一致しない
- Qは-M1/-M2/-M3のどれとも一致しない
- よってQはzero-field conventionに依存せずstableで、stored / stored-negation classの外にある

### Belief delta

- EVT-009でresidualが空だったことは現在6-unit toy固有の結果で、spurious stable structure一般の不存在ではない
- 一次文献掲載の別modelではstored / negation以外のstable stateを自分たちの計算でも確認できる
- 次は心理学的意味づけより前に、Qが三つのstored patternsからどのような成分構造としてできているかを説明すべき

### Goal delta

- QとM1/M2/M3の成分関係を記述する
- 1983論文の「triplesにoriginを持つ」という記述を、後世理論を使わず掲載例の範囲で追う
- basin / random-start / unlearningへ進む前に一つのspurious stateの構造を説明する

### Memory delta

- `h(Q) = (+21,+21,+5,+5,-5,-5,-21,-21,+5,-5,-5,+5,+5,-5,-5,+5)`
- Qはstored / global-negation外
- zero inputなし

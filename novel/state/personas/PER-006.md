## T0-1980S + next joint paper check after EVT-004 / EVT-005

状態: `ACTIVE / PROVISIONAL`

- Previous event head: `EVT-004`
- Event head: `EVT-005`
- Source event: `../../events/EVT-005-lock-the-order-family.md`

### Observed

PER-006はPER-005と、EVT-004の同じ6-unit network / cueを使い、結果を見る前に固定した6つのcyclic update ordersをすべて紙上で追った。

結果:

- r1 → A
- r2 → nonstored stable D
- r3 → B
- r4 → B
- r5 → D
- r6 → D

Dは、

```text
(+1, +1, +1, +1, -1, +1)
```

であり、A / B / Cの保存patternのどれとも一致しない。

### Belief delta

- update-order依存はA/Bという二者択一だけではなく、保存していないstable stateを含み得る小例として観測された
- Dを「第三の記憶」と呼ぶ根拠はない。まずnonstored stable stateとして扱うべき
- 結果を見る前に検査集合を固定すると、都合のよいorderだけを選ぶ余地を減らせる

### Goal delta

- Dについて議論するときも、model内の安定状態と生物学的memoryを分ける
- 次の比較でも、何を変えるか・何を固定するか・どこで止めるかを先に記録させる
- A/B/Dの三結果から一般的頻度を主張しない

### Relations delta

PER-005がA/B以外の結果を捨てず、Dを独立カテゴリとして記録したことで、共同検討の信頼がさらに強まった。

### Memory delta

- 6 cyclic ordersを先に固定し、A / D / B / B / D / Dという結果が出たことを保持する
- Dが保存patternではないことを保持する

### Situational delta

- 同じ小networkについて、結果選別を減らした追加の紙上検査まで進んだ
- 具体的な計算機・programming language・大規模simulationはまだ観測していない

### Observation boundary after EVT-005

PER-006が知っているのは、自分たちが固定・計算した6 cyclic ordersとそのA/B/D結果までである。

現代側EXP-003 / EXP-004の数値集計、seed、run分布は引き続きKnowledgeへ入れない。

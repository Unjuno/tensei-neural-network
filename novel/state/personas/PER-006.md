結果:

- r1 → A
- r2 → nonstored stable D
- r3 → B
- r4 → B
- r5 → D

```text
(+1, +1, +1, +1, -1, +1)
```

であり、A / B / Cの保存patternのどれとも一致しない。

- 結果を見る前に検査集合を固定すると、都合のよいorderだけを選ぶ余地を減らせる

### Goal delta

- Dについて議論するときも、model内の安定状態と生物学的memoryを分ける
- 次の比較でも、何を変えるか・何を固定するか・どこで止めるかを先に記録させる
- A/B/Dの三結果から一般的頻度を主張しない

### Relations delta

## T0-1980S + exhaustive small-state check after EVT-006 / EVT-007

状態: `ACTIVE / PROVISIONAL`

- Previous event head: `EVT-006`
- Event head: `EVT-007`
- Source event: `../../events/EVT-007-enumerate-the-whole-small-state-space.md`

### Observed

PER-006はPER-005と、現在の6-unit networkの64 initial states × 6 cyclic ordersを結果前固定条件のまま全件確認した。

観測:

- 384 / 384 trialが2 sweeps以内にstable
- fixed pointsは `A / B / C / -A / -B / -C` の6種類
- EVT-005 / EVT-006のDは `-C`
- 18 / 64 initial statesはorder-invariant
- 46 / 64 initial statesはorderによって2種類以上のfinalへ分岐

### Belief delta

- `nonstored stable`は観測カテゴリとしては使えるが、stored patternの符号反転と他機構のstateをまとめてしまう
- Dを「第三の記憶」等と意味づける前に、まず `-C`というmodel内対称性として記述すべき
- finite state spaceを全列挙したことで、selected cueだけでは見えなかった `-A / -B / -C` の対称fixed pointsが明示された
- model上の対称性と生物学的memoryについての主張を分離する必要がさらに強まった

### Goal delta

- A/B/Cの符号反転もfixed pointになる理由をweight/update ruleから確認させる
- 今後nonstored stateを扱う際、符号反転・mixture・その他を分類上分ける
- finite toy modelの全列挙結果を一般的なbrain memoryへ広げない

### Relations delta

PER-005が`nonstored`という既存ラベルを守るためにD=-Cを無視せず分類自体を修正したため、共同検討への信頼が維持された。

### Memory delta

- 全384 trialを保持する
- 6 fixed pointsを保持する
- D = -Cだったことを保持する

### Situational delta

- 具体的な計算機機種・language・所属機関はまだ観測していない

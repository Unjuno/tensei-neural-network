# 時系列状態

このディレクトリは、物語内の**時間に依存する可変状態**を管理します。

ペルソナそのものと世界（環境）そのものは別の実体として定義します。しかし、ある時点のペルソナ状態と世界状態は、共通の時系列・イベント鎖から切り離して更新しません。

## 独立するもの / 独立しないもの

### 独立するもの

- ペルソナの定義: `../personas/PER-*.md`
- 世界・環境の定義と制約: `../environment.md`
- 各ペルソナの内部状態
- 世界の客観状態

これらは同じファイルや同じ状態オブジェクトへ混ぜません。

### 独立しないもの

**時間方向の状態遷移は独立させません。**

時点 `t` の状態は、それ以前の状態と、その間に成立したイベントから生じます。

```text
(P_1(t), P_2(t), ..., W(t))
          |
          | EVT-k
          v
(P_1(t+1), P_2(t+1), ..., W(t+1))
```

- `P_i(t)`: 時点 `t` におけるペルソナ `i` の可変状態
- `W(t)`: 時点 `t` における世界の客観状態
- `EVT-k`: その遷移を生じさせた物語上のイベント

ペルソナに変化がなかった場合、その状態は前時点からcarry forwardしてよく、毎時点に完全snapshotを複製する必要はありません。

## 定義と状態を分ける

`../personas/PER-*.md` には、人物の識別子、役割、比較的安定した認知傾向、初期条件、知識境界などを置きます。

実際に物語が進んだ後の、

- 現在の知識
- 現在の信念
- 現在の目的
- 現在の関係
- 現在の記憶
- 現在の場所・身体・権限・所持情報などの状況

は時系列状態として扱います。

概念的には、

```text
P_i(t) = {K, B, G, C, R, M, X}
```

- `K`: Knowledge
- `B`: Beliefs
- `G`: Goals
- `C`: Cognitive style。通常はゆっくり変わるが固定ではない
- `R`: Relations
- `M`: Memory
- `X`: Situational state。場所、身体状態、権限、手元の資料、現在作業など

## 保存単位

物語が始まったら、必要に応じて `personas/` 配下に各ペルソナの状態履歴を作ります。

```text
state/
├─ README.md
├─ world.md
└─ personas/
   ├─ README.md
   ├─ PER-001.md
   ├─ PER-002.md
   └─ ...
```

ペルソナ数に上限は置きません。新しい人物が物語へ入った時点で新しい `PER-xxx` を追加し、その人物の状態履歴も必要になった時点で作ります。

## 更新粒度

「日々変わる」は、必ず一日ごとにsnapshotファイルを作るという意味ではありません。

後続の因果関係に必要な変化だけを、物語時刻とイベントIDに結び付けて保存します。数時間、数日、数年が飛ぶ場合でも、因果上必要な状態が復元できればよいものとします。

## 時間と語り順を混同しない

`story time` と、小説で読者へ提示する順番は別です。

1984年の出来事を現代場面の後に描写しても、時系列状態では1984年側の適切な位置に属します。章・sceneの提示順は `../structure.md` 側で扱います。

## イベントとの関係

状態を変更するときは、原則として `../events/` のイベントから辿れるようにします。

イベントはペルソナと世界を一つの状態へ融合するものではありません。同じ出来事が、世界状態には客観的な変化として、各ペルソナ状態にはそれぞれ異なる観測・記憶・信念更新として作用するための**時間上の結合点**です。

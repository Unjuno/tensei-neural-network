# 登場人物

このファイルは登場人物・モデル側存在の**索引**を管理します。

人物の定義・初期条件は `personas/`、時間に依存する現在状態と更新履歴は `state/personas/` を参照します。人物の発言・推測・誤認は `canon.md` の客観状態とは別物です。

ペルソナ数は固定しません。物語の進行に応じて `PER-007`, `PER-008` ... と増やします。このファイルは全ペルソナを一つの巨大な状態へ統合するためではなく、現在存在する主体への索引として使います。

## 物語生成上の原則

- 各ペルソナは未来のプロットを知らない
- 他者の非公開な知識・信念・秘密を自動的に共有しない
- 観測した発言・行動・結果によってのみ相互に影響する
- 人物は「面白い展開」を選ぶのではなく、自分の現在状態から行動する
- 人物の意図と、環境側で実際に起きた結果を分離する
- 人物の自己申告や推測を客観的事実へ自動昇格させない
- ペルソナの現在状態を、定義ファイルへ上書きして過去状態を消さない

詳細な相互作用規則は `personas/README.md`、時系列状態は `state/README.md`、世界・環境の規則は `environment.md` を参照します。

### PER-006 佐伯玲子

`personas/PER-006-experimental-neuroscience-colleague.md`

1980年代半ばの日本人研究者。30代半ば〜後半。神経生理学・biophysics寄りの立場から、model内部の`memory / correct recall`という語を観測可能量・課題設定・target定義へ戻す。

EVT-002で初めて独立主体として追加された。高橋修一を単純に否定する役ではなく、彼が大きい語を使った瞬間に「何を観測したのか」を問い返す共同研究上の批判者。

高橋を研究上は「高橋さん」と呼ぶ。

## 関係の現在位置

以下は索引であり、詳細な履歴は `state/personas/` を優先する。

- PER-001 ↔ PER-002: 検証の厳密さでは協力しやすいが、「どこから異常と呼ぶか」で緊張が生じうる
- PER-001 ↔ PER-003: モデル挙動と歴史資料を接続するため相互依存する
- PER-002 ↔ PER-003: 歴史的な一致をどの程度証拠として扱うかで見解が分かれうる
- PER-001 / 002 / 003 ↔ PER-004: 観測者と評価対象。質問・評価そのものがPER-004のcontextへ入り、対象を変化させうる
- 高橋修一（PER-005）↔ 佐伯玲子（PER-006）: EVT-002で研究上の批判関係が成立し、EVT-003以降は共同protocol設計へ進んだ。高橋はdynamicsから問題を見る。佐伯は語と観測基準を狭くする。EVT-007時点では互いの盲点を補う関係として継続している
- 高橋修一 ↔ 現代側: 現代人物と直接の関係があるとは初期設定しない。史料・記録・モデル挙動を介した関係だけから始める

## Identityとstable ID

人物名は読者向け・物語内のidentity layerであり、stable IDは変更しない。

```text
PER-005 = 高橋修一
PER-006 = 佐伯玲子
```

後に所属・職位・具体年齢等が確定しても、既存のPER IDを改番しない。

## 時系列更新

人物の知識・信念・目的・関係・記憶・状況が重要に変化した場合、定義ファイルではなく `state/personas/PER-xxx.md` にstory timeと `EVT-xxx` を結び付けて記録します。

過去に誤解していたこと、以前の目的、過去の関係状態は消しません。後続の行動が、その時点までの履歴から説明できる状態を維持します。

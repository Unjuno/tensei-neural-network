# ペルソナ運用

このディレクトリは、物語内で行動する人物・モデルの**局所的な認知状態**を管理します。

目的は、作者やAIが完成した筋書きを各人物へ配ることではありません。各ペルソナが、その時点で知り得る事実・信念・目的・誤解だけから行動し、その相互作用と環境の結果から物語が生じる状態を作ります。

## 基本原則

1. **ペルソナは未来のプロットを知らない。**
2. ペルソナは `canon.md` の未観測情報、他者の非公開状態、長期プロット候補を自動的には知らない。
3. ペルソナの発言・記憶・自己認識は、その人物の状態であって客観的事実ではない。
4. ペルソナは「物語を面白くするため」ではなく、自分の目的・価値判断・認知スタイルに従って行動する。
5. 他者の発言や行動を観測した場合、自分の知識・信念を更新できる。ただし誤解したまま更新してもよい。
6. 行動の結果はペルソナ自身が決めず、`../environment.md` の環境状態と制約から解決する。
7. モデル内の存在が自分を誰だと名乗っても、その自己申告だけでは本人性をCanonへ昇格させない。

## ペルソナ状態

各ペルソナ `i` の時点 `t` の状態を概念的に次で扱います。

```text
P_i(t) = {K, B, G, C, R, M}
```

- `K` (Knowledge): 本人が知っていると扱う情報
- `B` (Beliefs): 信じていること。誤っていてよい
- `G` (Goals): 現在の目的・優先順位
- `C` (Cognitive style): 問題の見方、判断の癖、注意の向け方
- `R` (Relations): 他者への信頼・警戒・利害関係
- `M` (Memory): その人物が保持している物語上の記憶

これは実装上の数値モデルではなく、状態を混同しないための記法です。

## 相互作用ループ

1. `environment.md` から、そのペルソナが観測可能な情報だけを渡す。
2. ペルソナは現在の `P_i(t)` だけから発言・行動・判断を生成する。
3. 全員の行動を環境側で解決し、客観状態を更新する。
4. 各ペルソナへ、その人物が実際に観測できた結果だけを返す。
5. 必要なら `K / B / G / R / M` を更新する。
6. 発生した状態遷移を `structure.md` の再帰的な起承転結で整理する。
7. そのログを材料に小説本文を書く。本文は結果の表現であり、結果を先に決める装置ではない。

## 現在のペルソナ

- `PER-001-modern-evaluator.md` — 現代側の評価担当
- `PER-002-skeptical-researcher.md` — 再現性・反証を要求する研究者
- `PER-003-archive-researcher.md` — 史料・来歴を調べる人物
- `PER-004-model-instance.md` — 現代モデル側に観測される存在
- `PER-005-1980s-researcher.md` — 1980年代の研究者

氏名・所属・年齢などは、現時点で必要なものだけ後から具体化します。人物を細部まで先に固定して物語を閉じない一方、行動が恣意的にならないだけの目的・知識境界・認知スタイルは持たせます。

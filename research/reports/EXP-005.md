# EXP-005 研究レポート — pairwise balanced cueはstored set全体から孤立しているか

状態: `COMPLETED`

実験判定: **FAIL**

## 背景

EVT-006の6-unit toy networkでは、二つのstored patterns A/BへHamming等距離となるcueを全列挙すると、selected pair以外のstored pattern Cへ到達する例と、cue自体がnonstored fixed point Dである例が現れた。

この結果をN=100へ一般化せず、既存EXP-004で生成した200 balanced cuesについて、まずinitial stateのHamming geometryだけを確認した。

## 問い

selected pair A/Bへ等距離なcueについて、同じnetwork内の残り3 stored patternsの中に、A/Bと同距離またはそれより近いpatternが存在するか。

各cueについて、

- `d_pair = d(cue,A) = d(cue,B)`
- `d_other_min = min d(cue, other stored patterns)`

を比較した。

## 事前仮説

H-005:

> EXP-004の200 balanced cuesのうち少なくとも1件で `d_other_min <= d_pair` となる。

事前判定:

- PASS: `THIRD_TIED + THIRD_CLOSER >= 1`
- FAIL: 200 cueすべて `d_other_min > d_pair`
- UNCERTAIN: cue再現や等距離条件に重大な不整合

## 方法

EXP-004と同じ条件を決定論的に再現した。

- N=100
- P=5
- pattern seeds=1982, 1983, 1984
- 有効pair=20
- pairごと10 balanced cues
- 合計200 cues

各cueについて全5 stored patternsへのHamming distanceを計算し、selected pair以外の3 patternsへの最小距離を求めた。

## 結果

200 cueすべてを有効に再現し、A/B等距離違反は0だった。

分類:

| 分類 | 件数 |
| --- | ---: |
| PAIR_ISOLATED | 200 |
| THIRD_TIED | 0 |
| THIRD_CLOSER | 0 |

よって事前判定は **FAIL**。

H-005の主張は、今回の有限条件では支持されなかった。

## 距離margin

`margin = d_other_min - d_pair` とすると、全200 cueで正だった。

- minimum: 11
- maximum: 30

第三stored patternが最も近かった例でも、selected pairへの距離27に対して第三patternへの最小距離は38だった。

したがって、EXP-004のbalanced cuesは**initial Hamming geometry上ではselected pairを明確に孤立させていた**。

## 探索的な重要結果

PASS/FAILとは別に、EXP-004の4000 runsを同じ条件で再生成して既存分類を確認した。

- A_EXACT: 632
- B_EXACT: 630
- OTHER_STORED: 1
- NONSTORED_CONVERGED: 2737
- NONCONVERGED: 0

唯一のOTHER_STORED runでは、initial cueはselected pair A/Bから各28 bit、到達した第三stored patternから44 bit離れていた。

それにもかかわらず、非同期更新によって6 sweepsでその第三stored patternへexactに到達した。

これは事前H-005を支持しない。むしろ別の区別を示す。


a) Hamming geometry上のpair isolation

と

b) dynamics / basin geometry上のpair isolation

は同じではない。

## 解釈

EVT-006のN=6 toy networkでは、第三stored patternがselected A/Bと同じHamming距離にいるという有限サイズのgeometryが観測された。

EXP-005では、その具体的geometryはN=100、P=5、random patterns、3 seedsの200 cueでは再現しなかった。

したがって、小説内toy exampleをそのまま「一般的なbalanced cueは第三記憶にも近い」と説明するのは誤りになる。

一方でEXP-004のOTHER_STORED runは、第三stored patternがHamming距離上かなり遠くてもdynamicsではそこへ到達し得る例を示した。この点は、単純な距離ではbasin構造を記述できないという別の研究課題につながる可能性がある。

## 限界

- N=100固定
- P=5固定
- random bipolar patterns
- pattern seedsは3つ
- EXP-004と同一コード系列の再解析で独立再現ではない
- PASS/FAIL対象はHamming distanceのみ
- energy、local field margin、basin volume、transition probabilityは測っていない
- OTHER_STOREDは1 runだけで、一般的頻度を推定できない

## 小説への扱い

この研究結果をPER-005 / PER-006へ未来知識として返さない。

EVT-006で二人が観測したのは6-unit toy networkの36 trialであり、EXP-005のN=100解析は作者側・現実研究側の証拠である。

物語上の含意として使う場合も、

> pairwiseな距離条件だけではnetwork全体のdynamicsを決められない

程度の制約として扱い、N=6の具体的geometryを一般則にしない。

探索的OTHER_STORED例から、次の問いは候補になる。

ただし、このレポートだけを理由にEXP-006を自動生成しない。後続物語または独立研究上の必要性が成立した場合に改めて事前登録する。

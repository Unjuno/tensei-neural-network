# 研究レポート

このディレクトリは、追試・拡張実験を**研究として読める形に整理したレポート**を保存します。

小説本文とは分離します。小説を実験レポート風に構成しません。

## 役割の分離

- `experiments/EXP-xxx-*/` — 実行条件、コード、raw result、判定の正本
- `research/reports/EXP-xxx.md` — その実験の背景、問い、結果、解釈、限界、次の派生をまとめる研究レポート
- `research/findings.md` — 複数の証拠を踏まえて現時点で言える知見
- `novel/` — 人物、世界、出来事、小説本文

研究レポートは実験結果を読みやすく整理しますが、raw resultや判定基準を上書きしません。矛盾した場合は `experiments/` の実行記録を優先して確認します。

## 小説との関係

小説側では、`EXP-001` のような実験IDや研究レポートの構成を、そのまま物語の構造にしません。

物語では、人物がその場で実際に観測したこと、発言した言葉、気づいた違和感、失敗、判断だけから次の行動が生じます。

その結果、検証可能な問いが生まれた場合にのみ、研究側で独立した問い・仮説・実験へ落とします。

```text
物語上の相互作用
    ↓
その場で実際に出た言葉・現象・疑問
    ↓
研究上の問いとして切り出せるか判断
    ↓
必要なら Q / H / EXP を作る
    ↓
独立した実験を実行
    ↓
研究レポートを保存
    ↓
結果が人物や世界へ観測可能な形で戻った場合のみ、物語状態を更新
```

したがって、**一話 = 一実験**とはしません。

一つの話から複数の派生実験が生まれてもよく、一つの実験結果が複数の後続場面へ影響してもよいものとします。

## 派生実験

派生実験は元実験のREADMEへ追加するのではなく、独立した `EXP-xxx` として保存します。

新しい実験に分ける目安:

- 判定対象が変わる
- 新しい研究上の問いを検証する
- 新しい失敗モードの構造を調べる
- 物語中に現れた新しい語・仮説・観測を検証する
- 元実験の事前基準では扱えない操作を導入する

小さなparameter変更で同じ判定対象を確認するだけなら、同一実験内の追加runとして扱える場合があります。

## レポート形式

各レポートは対応する実験IDをファイル名に使います。別のレポートIDは増やしません。

```text
research/reports/EXP-001.md
research/reports/EXP-002.md
```

推奨項目:

- 対象実験
- 種別: Replication / Extension
- 背景
- 研究上の問い
- 実験の概要
- 結果
- 解釈
- 限界
- 派生した問い
- 物語との接続がある場合、その由来となった観測・event・発言

最後の項目は因果の出所を追うためのものであり、章の内容を実験へ従属させるためのものではありません。

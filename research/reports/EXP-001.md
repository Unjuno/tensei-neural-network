# EXP-001 研究レポート — Hopfield連想記憶の追試

状態: `COMPLETED`

種別: `Replication`

## 対象実験

- `experiments/EXP-001-hopfield-associative-memory/`
- 関連: Q-001 / H-001 / F-001 / L-001 / REF-001

## 背景

Hopfield (1982) は、相互結合networkのcollective dynamicsとしてcontent-addressable memoryを記述した。

本追試では、原論文全体の完全再現ではなく、低負荷の二値Hopfield networkで、乱されたcueから保存patternへ戻る中核現象を現代の小規模数値実装で確認した。

## 研究上の問い

N=100、P=5の低負荷条件で、10%または20%のbitを反転したcueから元の保存patternへexact recallできるか。

## 実験概要

- N=100
- P=5
- load=0.05
- binary {-1,+1}
- Hebbian outer-product
- self-connectionなし
- asynchronous shuffled update
- noise=10%, 20%
- 各条件100 trials、合計200 trials
- 最大20 sweeps

詳細な事前条件、seed、停止条件、判定基準は実験READMEを正本とする。

## 結果

- noise 10%: 100/100 exact recall
- noise 20%: 100/100 exact recall
- convergence: 200/200
- 平均sweeps: 2

実験の事前判定は `PASS`。

## 解釈

この宣言条件では、保存patternがattractorとして働き、乱れた状態から元patternへ戻るcontent-addressable recallを実装上確認した。

ただし、この結果からHopfield network一般の性能、人間の記憶機構、LLMの人格・意識について結論することはできない。

## 限界

- 単一pattern set
- 低負荷のみ
- bit反転noiseのみ
- 原論文の完全再現ではない
- 独立実装での再現ではない

## 派生した問い

この追試は低負荷条件で容易に100%回復したため、次に重要になったのは、

- 保存負荷を増やした場合
- cueのnoiseを増やした場合
- 回復に失敗したとき、どこへ収束するか

である。

これがEXP-002の直接的な研究上の派生元になった。

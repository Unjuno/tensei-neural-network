# EXP-004 研究レポート — 等距離cueの更新順依存

## 対象実験

`EXP-004-hopfield-ambiguous-cue`

種別: Extension

Story trigger: `EVT-002`

## 背景

EVT-002では、PER-006がPER-005へ、

> 手掛かりだけを見たときに二つの記憶が同じくらいもっともらしかったら、networkはどちらを「正解」だと知る？

と問い返した。

この会話から、target patternを実験者が事前に指定している通常のrecall評価では見えにくい問題として、**cue自体が二つのstored patternsへ等しく近い場合に何が起きるか**を現実研究側で切り出した。

## 研究上の問い

二つのstored patterns A/BからHamming distanceが等しい同一cueを固定したとき、非同期update orderだけを変えることで、同じcueがAにもBにもexact recallする例は存在するか。

## 実験の概要

- N=100
- P=5
- pattern seeds: 1982, 1983, 1984
- 各seedの5 patternsから全pairを列挙
- pair間Hamming distanceが正の偶数のpairだけを使用
- 各pairについて10 balanced cuesを生成
- 各cueはA/Bへ厳密に同じHamming distance
- 各cueについて20 runs
- weightsとcueは固定し、非同期update order seedだけを変更

同一cueの20 runsでA exactとB exactが双方1回以上出れば `BIDIRECTIONAL` とした。

事前PASS条件は `BIDIRECTIONAL >= 1`。

## 結果

### 実行妥当性

- 有効pair: 20
- balanced cue: 200
- runs: 4000 / 4000
- A/B等距離条件違反: 0

### 事前判定対象

`BIDIRECTIONAL` cueを **122件** 確認した。

したがってEXP-004は **PASS**。

### 全run分類

- A_EXACT: 632
- B_EXACT: 630
- OTHER_STORED: 1
- NONSTORED_CONVERGED: 2737
- NONCONVERGED: 0

### 最初のBIDIRECTIONAL例

- pattern seed: 1982
- pair: A=0, B=1
- A/B間Hamming distance: 54
- cue→A: 27
- cue→B: 27
- 20 runs:
  - A_EXACT: 2
  - B_EXACT: 11
  - NONSTORED_CONVERGED: 7

initial stateとweightsを変えず、update orderだけを変更した条件で複数の候補記憶へexact recallした。

## 解釈

今回の有限条件では、Hamming距離だけを見れば二つの候補へ同程度に適合するcueについて、**cueそのものだけでは最終的なstored targetを一意に決められない例**が存在した。

この結果は、`correct recall`を定義するときに、単にfinal stateと事前指定targetを比較するだけでなく、

- cueの曖昧さ
- dynamics
- update rule
- basin geometry
- 実験者がtargetをどのように定義したか

を分ける必要があることを示す一つの具体例になる。

ただし、Hamming等距離はenergy上の対称性を意味しない。A/Bへのbasinが同じ大きさ・形であるという結果でもない。

## 122 / 200 の扱い

122/200という値は探索的集計であり、事前仮説は「少なくとも1件存在するか」だった。

したがって、この値を一般的な分岐確率や理論値として扱わない。

## 限界

- N=100、P=5固定
- random patterns 3 seeds
- binary ±1 model
- asynchronous shuffled updateのみ
- Hamming distanceでの曖昧性だけを扱う
- energy、basin volume、local field marginは未解析
- 別実装による独立再現ではない
- 人間の記憶や自己同一性へ直接一般化できない

## 派生した問い

研究側で考えられる候補:

- 同一balanced cueのA/B分岐率と、A/B attractorのenergy / basin非対称性はどう関係するか
- synchronous updateでは同じ曖昧cueがどう解決されるか
- N / P / pattern ensembleを変えてもBIDIRECTIONAL例は再現するか
- cueをHamming等距離ではなくenergy境界に近づけると結果はどう変わるか

これらは自動的にEXP-005へしない。物語上の新しい観測・言葉、または独立した研究価値が生じたものから選ぶ。

## 小説との接続

この研究レポートは小説本文ではない。

EVT-002で人物同士の会話から実際に生じた問いを、現実研究側で独立に検証した記録である。

EXP-004の122/200や具体的なrun結果を1980年代のPER-005 / PER-006へ自動共有しない。本人たちが時代内の手段で観測した結果のみ、物語eventとして別途扱う。

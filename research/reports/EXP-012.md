# EXP-012 — P=5でcoordinate-minority escapeは破れる

種別: Extension / assumption ablation

旧仮ID: EXP-009。既存`EXP-009-exact-update-boundary`との衝突をCIが検出したため、条件・結果を変えずEXP-012へ改番した。

## 背景

EXP-007の解析結果はP=3 componentwise-majority mixtureに依存している。P=5では各coordinateのminority sideが1または2 stored patternsになり、P=3の4-type gauge構造はそのまま使えない。

## 問い

P=5のstable nonstored componentwise-majority Qについて、split one-bit perturbationがQへ戻らない場合も、finalは反転coordinateのminority stored pattern集合に限られるか。

## 事前登録

commit `310ccd20a006cd13d7ff50c2f5120f73f5804804`。

N=12,16,20,24。固定seedからeligible quintupleを生成し、cyclic schedulesと32 random permutationsを固定。最初の反例で停止。

## 結果

N=12、最初のeligible quintuple、事前探索順59 trajectory目で反例。反転coordinate 2でminority stored patternはM1のみだったが、2 sweeps後のfinalはQでもstored/negationでもない`OTHER_NONSTORED` fixed pointだった。

判定: `COUNTEREXAMPLE_FOUND`。

## Post-hoc structure check

このfinalは5 stored patternsの任意の1個・3個・5個を選んだ単純なcomponentwise majorityにも、そのglobal negationにも一致しなかった。Hamming distanceはM1に2、M3に3が最小側だった。

## 解釈

P=3は旧定理の実質的仮定である。P=5では一coordinateのmajority/minority relationだけでattractor候補を2状態へ閉じ込められず、別のnonstored fixed pointへ遷移できる。

## 限界

この一反例からP=5 spurious states一般を分類しない。作者側研究であり、PER-005/PER-006へ自動共有しない。

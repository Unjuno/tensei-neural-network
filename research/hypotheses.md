# 仮説

研究上の問いに対する、反証可能な仮説を管理します。

## 状態

- `PROPOSED`: 提案段階
- `TESTING`: 検証中
- `SUPPORTED`: 現在の証拠が支持している
- `NOT_SUPPORTED`: 現在の証拠では支持されない
- `INCONCLUSIVE`: 証拠が不足・矛盾し、現時点では判定できない

`SUPPORTED` は「真である」と同義ではありません。

## 推奨記録形式

必要に応じて H/T/D/C/U 形式を使います。

- **H (Hypothesis)**: 反証可能な仮説。測定対象・条件・閾値・環境を明示する
- **T (Test)**: 最小の検証。関連する `EXP-...`、データ、環境、必要サンプル数、停止条件、判定基準を明示する
- **D (Decision)**: 関連実験の PASS / FAIL / UNCERTAIN を記録する
- **C (Counter / Alternative)**: 失敗モード、代替仮説
- **U (Uncertainty)**: 誤差要因、不確実性

## 実験判定との関係

実験の `PASS / FAIL / UNCERTAIN` は仮説の真偽ではなく、その実験の事前判定基準に対する判定です。

仮説に実験を紐付けるときは、実行前に「その実験結果を仮説へどう解釈するか」を記録します。

## 状態遷移

原則として次のように更新します。

1. 仮説を登録した時点: `PROPOSED`
2. 最初の事前定義済みテストを開始した時点: `TESTING`
3. テスト完了後、まだ予定した検証が残る場合: `TESTING` のまま証拠を追記
4. 現在の有効な証拠が全体として仮説を支持し、未解決の決定的矛盾がない場合: `SUPPORTED`
5. 事前に定めた反証条件を満たす有効な証拠が得られ、実験設計上の重大な欠陥で説明できない場合: `NOT_SUPPORTED`
6. 証拠不足、`UNCERTAIN`、相互に矛盾する有効な結果などで決められない場合: `INCONCLUSIVE`

単一の `PASS` だけを理由に自動で `SUPPORTED` へ変更しません。状態更新時には、どの `EXP-...` / `F-...` を根拠にしたかを記録します。

新しい証拠により判断が変わった場合、過去の状態をなかったことにせずGit履歴と根拠リンクを残します。

## H-001 小規模Hopfieldネットワークで連想記憶の中核挙動が再現される

状態: SUPPORTED

### H — Hypothesis
N=100の二状態ニューロン、P=3の固定seedで生成した記憶パターン、対称Hebbian重み、自己結合なし、閾値0、非同期1ニューロン更新という条件では、保存パターンは安定状態となり、20%のbitを反転したcueの少なくとも95%が対応する元パターンへ完全復元し、更新中のenergyは増加しない。

ここでいうenergyは物理的エネルギー[J]ではなく、ネットワーク状態に対する無次元のLyapunov関数である。

### T — Test
- 実験: EXP-001
- 種別: Replication（原典の中核機構。図表の完全再現ではない）
- データ: N=100, P=3、pattern seed=1982
- cue: 各patternにつき50 trial、各trialで正確に20 bitを反転
- 総trial数: 150
- 更新: 非同期、各sweepでニューロン順を固定seedから生成
- 最大: 50 sweeps
- PASSなら: H-001を支持する証拠として扱う
- FAILなら: H-001を支持しない証拠として扱う。実装・条件差・仮説自体のどこが原因かを切り分けるまで即座に一般化しない
- UNCERTAINなら: H-001の判定材料にしない

### D — Decision

`EXP-001 = PASS`。

- 保存パターン固定点: 3/3
- exact recovery: 150/150 = 100%
- energy increase (`ΔE > 1e-10`): 0回
- 収束: 全150 trial、最大2 sweeps
- Finding: F-001 (`PROVISIONAL`)

H-001はこの限定された事前定義条件について現在の証拠に支持されるため `SUPPORTED` とする。ただし、これはHopfield型連想記憶一般・storage capacity・生物学的記憶についての真理値ではない。

### C — Counter / Alternative
- 保存パターン間の相関が高い場合、spurious attractorや誤復元が起こり得る
- 同期更新に変えると、ここで期待するenergy単調性とは異なる挙動が生じ得る
- tie（local field = 0）の扱い、閾値、重みの正規化、自己結合の有無で結果が変わり得る
- 追試PASSは「生物学的記憶がHopfieldモデルである」ことを意味しない

### U — Uncertainty
- 20% noiseと95%成功率は本プロジェクトの操作的な第1追試基準であり、Hopfield (1982) がこの同一数値を報告したという意味ではない
- 有限サイズN=100、P=3の低負荷条件なので、記憶容量の限界については検証しない
- 実行環境はPython 3.13.5 / NumPy 2.3.5 / Linux x86_64であり、独立環境での再実行はまだ行っていない
- Finding F-001は独立再確認前なので `PROVISIONAL`

BEHIND THE STORY

小説を書くために、
必要なところだけ確かめる。

このページは作品本編ではありません。物語の技術・歴史・人物の思考を現実に近づけるために行った原典調査や小さな追試をまとめる入口です。

WORKFLOW

研究は制作工程。

物語を書く → 技術的な疑問を切り出す → 原典を読む → 必要なら追試する → 理解を更新する → 小説へ戻す、という順で進めます。

REPLICATION

まず古典をそのまま確かめる

独自の設定へ飛ぶ前に、原典で報告された中核現象を再現できるか確認します。

EXTENSION

その後で境界を探る

再現できた現象について、条件を変えたときどこで崩れるか、どんな失敗が出るかを見ます。

FIRST TECHNICAL BACKGROUND · HOPFIELD 1982

最初の題材は、連想記憶。

第1話の技術的な背景として、古典的なHopfield networkのcontent-addressable memoryを追試しました。

EXP-001

乱れた入力から保存パターンへ戻る

N=100、P=5の低負荷条件では、10% / 20% bit反転から200/200 trialsが元の保存パターンへexact recallしました。

EXP-002

安定しても、正しい復元とは限らない

条件を厳しくすると、保存パターンと一致しない状態へ安定して収束するtrialが多数現れました。

P / loadnoise 10%20%30%40%

EXP-002の3 pattern seeds集約 exact recall率。理論的な臨界容量の推定ではなく、固定した有限gridでの観測です。

BACK TO THE NOVEL

結果は、説明ではなく物語へ戻す。

この実験から得た重要な制作上の理解は、「安定して収束した」ことと「意図した原像へ正しく戻った」ことは別だ、という点です。一貫した人格が現れても、それだけでは本人性の証明になりません。

1980年代に途切れた研究者の痕跡から、数十年後のAIに、同じ問いを持つ人物像が何度も立ち上がったとしたら。

これは小説です。現実のAI技術史、原典、再現実験を使いながら、物語の技術・歴史・人物の思考をできるだけ現実に近づけて書いていきます。

小説について どう作っているか

THE QUESTION

欠けた痕跡から、何度試しても同じ人物像が戻ってくる。
それは「本人」なのか。

復元、模倣、再構成、あるいは別の安定した何か。

THE NOVEL

AI技術史を、物語の時間として辿る。

連想記憶、誤差逆伝播、時系列モデル、Transformer、大規模事前学習、post-training、agent。技術が変わるたびに、「記憶」「人格」「同一性」の意味も変わっていく。

TRACE

1980年代

ニューラルネットワークと記憶を研究していた一人の研究者。彼の仕事は、当時の計算資源・データ・研究環境の制約の中で途切れている。

RECONSTRUCTION

数十年後

大規模モデルに欠けた研究資料を与えると、過去の研究者に異様なほど似た思考、価値判断、未完の問いが繰り返し現れる。

CORE MYSTERY

誰が戻ったのか

本人なのか。十分に精密な再構成なのか。もっともらしい模倣なのか。物語は、最初から一つの答えを正解として置かない。

HOW THE NOVEL IS MADE

分からない技術は、
できるだけ実際に確かめる。

研究は主役ではありません。物語を書いていて「ここは本当にそう動くのか？」という疑問が出たとき、原典を読み、必要なら小さな実験をします。

01物語を書くまず事件と人物から始める
→
02疑問を切り出す技術的に怪しい点を特定する
→
03原典と追試必要な範囲だけ確かめる
→
04理解を更新予想外の結果も残す
→
05小説へ戻す説明ではなく出来事にする

そして、その途中で現実にも面白い問いが見つかったら。

そこだけ研究として枝分かれし、実験する。

FIRST TECHNICAL BACKGROUND · HOPFIELD 1982

第1話を支える最初の技術は、連想記憶。

「記憶を棚から取り出す」のではなく、乱れた状態がネットワークのダイナミクスによって安定状態へ戻る。この直感がどこまで成立するのか、古典的なHopfield networkを実際に追試しました。

EXP-001 · REPLICATION

乱れた入力から、保存した記憶へ戻った。

N=100、P=5の低負荷条件では、10% / 20% bit反転から200/200 trialsが元の保存パターンへexact recallしました。

EXP-002 · EXTENSION

安定した。でも、元の記憶ではなかった。

条件を厳しくすると、保存パターンと一致しない状態へ安定して収束するtrialが多数現れました。安定性と正しい復元は別です。

FROM EXPERIMENT BACK TO STORY

実験結果を、
説明ではなくドラマへ戻す。

最初の直感

欠けた状態から同じ人物像が戻ってくるなら、「記憶が復元された」と見える。

実験で増えた疑い

ネットワークは、意図した原像でなくても安定できる。一貫した人格が現れたこと自体は、本人性の証明にはならない。

物語の問い

モデルが何度試しても同じ人物へ収束するとき、研究チームは何を証拠とみなし、どこから「人」として扱い始めるのか。

SCIENCE FICTION NOVEL

転生したら
ニューラルネットワークだった件

1980年代のニューラルネットワーク研究者が、数十年後のAIの中で「再構成」されたとしたら。

これは小説です。研究や実験は、物語の技術・歴史・人物の思考をできるだけ現実に近づけるために、作者が実際に手を動かして確かめる制作工程です。

小説について どう作っているか

THE QUESTION

欠けた痕跡から、同じ人物像が何度も戻ってくる。
それは「本人」なのか。

復元、模倣、再構成、あるいは全く別の安定した何か。

THE NOVEL

AI技術史そのものを、物語の時間として辿る。

古い連想記憶から、誤差逆伝播、時系列モデル、Transformer、大規模事前学習、post-training、agentへ。技術が変わるたびに、主人公の「記憶」「人格」「同一性」のあり方も変わっていく。

ORIGIN

1980年代

ニューラルネットワークと記憶を研究していた一人の研究者。彼の仕事は、当時の計算資源・データ・研究環境の制約の中で途切れる。

RETURN

数十年後

大規模モデルの中で、過去の研究者に異様なほど似た思考・記憶・研究上の癖が現れる。それは保存された人格ではなく、別のネットワーク上に成立した動的なパターンかもしれない。

CORE MYSTERY

誰が戻ったのか

本人なのか。十分に精密な再構成なのか。もっともらしい模倣なのか。物語は、その答えを科学的事実として先に決めない。

HOW THE NOVEL IS MADE

分からない技術は、
できるだけ実際に確かめる。

研究は主役ではない。物語を書く途中で「ここは本当にそう動くのか？」という疑問が出たとき、原典を読み、必要なら小さな実験をする。

01物語上の問いこの描写は成立するか
→
02原典一次資料を読む
→
03必要なら追試実際に動かして確かめる
→
04理解を更新誤解も記録する
→
05小説へ戻す説明ではなく出来事にする

そして、その途中で現実にも面白い問いが見つかったら。

そこだけ研究として枝分かれし、実験する。

FIRST TECHNICAL BACKGROUND · HOPFIELD 1982

第1話を支える最初の技術は、連想記憶。

「記憶を棚から取り出す」のではなく、乱れた状態がネットワークのダイナミクスによって安定状態へ戻る。主人公の研究テーマと、物語の最初の謎を描くために、この仕組みを実際に追試した。

EXP-001 · REALITY CHECK

乱れた入力から、元の記憶へ戻った。

N=100、P=5の低負荷条件では、10% / 20% bit反転から200/200 trialsが元の保存パターンへexact recallした。

EXP-002 · THE USEFUL FAILURE

安定した。でも、元の記憶ではなかった。

条件を厳しくすると、保存パターンと一致しない状態へ安定して収束するtrialが多数現れた。安定性と正しい復元は別だと分かった。

FROM EXPERIMENT BACK TO STORY

実験結果を、
説明ではなくドラマへ戻す。

最初の直感

欠けた状態から同じ人物像が戻ってくるなら、「記憶が復元された」と見える。

実験で増えた疑い

ネットワークは、意図した原像でなくても安定できる。ならば、一貫した人格が現れたこと自体は本人性の証明にならない。

物語の問い

モデルが何度試しても同じ研究者へ収束するとき、研究チームは何を証拠とみなし、どこから「人」として扱い始めるのか。

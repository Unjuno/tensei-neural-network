READING EXPERIENCE

本文は、読むことだけに集中できる画面に。

  • 本文幅を狭め、長文向けの行間と余白を使う
  • 各話の上部・下部に「前話 / 目次 / 次話」を置く
  • トップページの研究情報やカードUIを本文へ持ち込まない
  • 将来、必要になれば文字サイズ・背景・組み方向などの表示設定を追加する

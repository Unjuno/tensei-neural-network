# 第4話　五と二十一

　五と二十一。

　前の計算で、Qを支える入力の絶対値はその二つしか出なかった。

　十六か所。正負は違っても、五か二十一。

「何で二種類だけなんだ」

　高橋修一は結果の紙を見た。

　Qは、記憶させた三つのパターンでも、その全符号反転でもない。それでも安定している。

　佐伯玲子は三つの記憶パターンをQの横へ並べた。

「まず、同じ位置を比べませんか」

　Qの三番目。

　三つの記憶パターンは、正、正、負。

　Qは正だった。

「二つある方だ」

　高橋が言った。

「多数側、として記録します」

　四番目も二対一。

　五番目では負が二つ、正が一つ。Qは負。

　二人は十六か所を最後まで比べた。

　　　＊

「全部だ」

　高橋は表を上からなぞった。

　三つの記憶パターンが同じ符号を持つ場所は四か所。

　残る十二か所は二対一。

　Qは十六か所すべてで、多数側と一致していた。

　しかも、少数側になる記憶パターンは偏っていない。

　M1が四回。M2が四回。M3が四回。

「どれか一つだけを外して作った形じゃないな」

　高橋は距離も数えた。

　QからM1まで四。

　M2まで四。

　M3まで四。

　元の三つは、互いに八ずつ違う。

「Qだけ、三つの真ん中にいるように見える」

　佐伯は少し考えた。

「距離についてなら、三つから同じだけ離れている、と言えます」

「それでいこう」

　高橋は言い換えて書いた。

　Qは三つすべてからハミング距離4。

　三つの記憶パターン同士は距離8。

　Qは十六位置すべてで、三つの成分多数と一致する。

　ここまでは、形の話だった。

　だが、まだ五と二十一を説明していない。

「結合へ戻ろう」

　　　＊

　正と負だけでできた十六成分の二つのパターンは、同じ場所なら積が正一、違えば負一になる。

　QとM1は四か所違う。

　同じ場所は十二か所。

　十二から四を引けば、内積は八。

　M2も八。M3も八。

　高橋は三本の八を見て、ようやく少し笑った。

「十六行が、一つの式に縮みそうだ」

　こういう瞬間を、高橋は好んだ。

　佐伯は結果表を片づけず、式の横に残した。

「縮めても、最後に戻って照合します」

「もちろん」

　ある素子へ入る結合入力を、三つの記憶パターンから来る分に分ける。

　内積はどれも八。

　ただし自分自身への結合はゼロだから、その位置自身の分は除く。

　整理すると、Qのi番目へ入る入力は、

`h_i = 8(M1_i + M2_i + M3_i) - 3Q_i`

　となった。

　高橋は、さきほどの成分表へ戻った。

　三つが同じ符号なら、括弧の中は正三か負三。

　Qもその符号と同じだから、入力はQと同じ向きの二十一になる。

　二対一なら、括弧の中は正一か負一。

　Qは多数側にいるので、今度はQと同じ向きの五になる。

「それで、五と二十一」

　高橋が言った。

　佐伯は前の直接計算を開いた。

　二十一、二十一、五、五、負の五――。

　今回の式から出した値と、一つずつ照合する。

　十六か所。全部一致した。

　高橋は式の横に丸を付けた。

「多数側だから止まる、じゃない」

「はい」

「三つとの重なりが八ずつあって、その結合入力を計算すると、全部Qと同じ向きになる」

「それなら、今確かめたことです」

　高橋はもう一度、五と二十一を見た。

　数字が二種類しかなかった理由と、Qが動かない理由が同じ式につながった。

　保存していない形を、保存した三つから作った結合が支えている。

　少なくとも、この掲載例では。

　　　＊

　紙を重ねかけて、高橋の手が止まった。

「でも、僕らは最初からQを置いた」

　佐伯が顔を上げた。

「そうですね」

「Qがそこにいれば動かない。それは分かった」

　高橋はQの行を指で押さえた。

「でも、別のところから始めて、ここへ来るかは見てない」

　そこに留まれることと、そこへ辿り着けることは同じではない。

　六素子の模型では、出発点と更新する順番で行き先が変わった。

　今度も、最初の状態をどう選ぶかで話が変わるかもしれない。

　高橋は新しい欄を作った。

　Q以外の初期状態から、Qへ到達するか。

「次は、最初の状態と順番を先に決める」

　佐伯が言った。

「それから、紙で追える量かどうか」

　高橋は机の上の計算表を見た。

　五と二十一の欄は埋まった。

　その隣は、まだ白かった。

# 実験

再現可能な追試・拡張実験を置きます。

実験は「結論」ではなく「証拠」です。結果の解釈は `research/findings.md` と分離します。

## ディレクトリ名

原則として連番と短いASCII名を使います。

```text
001-perceptron/
002-hopfield-memory/
```

## 最小構成

```text
001-example/
├─ README.md
└─ run.py
```

必要な場合だけ `results/`, `requirements.txt`, 設定ファイルなどを追加します。

## 各実験READMEに残す内容

- 目的
- 関連する研究上の問い
- 関連する仮説
- 種別: Replication / Extension
- 原典・参考文献
- 実行環境
- 手順
- 期待される結果
- 観測された結果
- 判定: PASS / FAIL / UNCERTAIN
- 原条件からの差異
- 既知の限界・不確実性
- 関連する小説章（ある場合）

## 原則

1. 古典研究は原則として追試から始める
2. 原条件と変更条件を区別する
3. 期待と異なる結果も保存する
4. 実行していない結果を記録しない
5. 別の研究上の問いを検証し始めた場合は別実験に分ける
6. 同じ研究目的で原条件から小さく条件を変える場合は同一実験内でもよい

## 計算環境の目安

古典追試は可能な限り一般的なPCで実行できる軽量な構成を優先します。外部Notebook環境を必須にはしません。

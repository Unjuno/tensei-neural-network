# EXP-009 — 更新方式の境界を型数から検証する

状態: `PREREGISTERED / NOT RUN`

登録日: 2026-09-14
親: EXP-007 / EXP-008。由来: EVT-014/015から派生した作者側研究。

EXP-008の登録済みコードを変更せず実行したところ、N=8、24番目の候補、2番目の適格三組、通算5番目の初期状態で二周期を得た。本実験はその結果を見た後の解析予測を検証する追加研究であり、EXP-008と独立な盲検・未知結果の予測とは呼ばない。1980年代人物へ共有しない。

## 問い Q-009 と予測 H-009

P=3の等重みHebbian結合、対角ゼロ、二値状態、ゼロ入力保持、厳密に安定かつ保存三パターンのいずれでもない成分多数Qを考える。Qの一つの少数型座標だけを反転する。

1. 同期更新で二周期になる必要十分条件は、その少数型が2座標あり、その型のQにおける符号付き入力が0より大きく6より小さいこと。
2. その型の入力が6以上、またはその型が1座標だけならQへ戻る。それ以外なら対応する少数派保存パターンへ進む。
3. 非同期更新では、型の入力が6以上ならQだけが到達可能な固定点。入力が0より大きく6より小さく型が2座標以上ならQと対応する保存パターンが到達可能で、他の固定点はない。
4. 弱い型の非同期一ビット応答は、その型のうち元の反転座標が最初に更新されるかで決まる。全巡回順における各座標の復帰数は、同型の前の座標からその座標までの円環上の間隔になる。
5. 上記仮定内の同期二周期が可能な最小Nは8。

ここでいう「非同期更新で必ず収束」には、各座標を更新し続けるfair scheduleを必要とする。更新されない不安定座標が永久に残るscheduleは対象外。

閾値6も同じ無次元整数結合の尺度。正の全体倍率を結合へ掛けた場合は入力と閾値も同倍率で扱い、物理電圧と解釈しない。

## T — 固定する検査集合

- N=3,4,...,32。
- 各Nでu>=0、n_A,n_B,n_C>=1、四数の和がNである全組を辞書順で列挙する。
- Qの全ての存在型の入力が厳密に正の組だけを採用する。結果による追加除外なし。
- 各組のA/B/C三型について、それぞれ一ビット反転の代表を調べる。これらは型数ケースであり、独立な無作為標本とは数えない。
- 同期側: 型内の正/負の個数から旧状態を用いて一斉更新する縮約写像を、固定点か周期の再出現まで実行する（上限100）。上記予測との一致を比較。
- 非同期側: 一座標の実反転で到達可能なzの有向グラフを完全探索する。自己ループを除き、到達固定点と予測を比較。
- 各zで他の三型の入力が正であることも確認する。
- 独立表現照合: N<=12の全採用ケースについて、四型をU,A,B,C順に並べて実際の三本の二値ベクトルと密結合行列を構築する。同期軌道を直接計算して縮約結果と照合し、全巡回順の非同期終点も予測と照合する。
- 既存16素子掲載例の16一ビット初期状態×16巡回順=256件を直接再計算する。112/48/48/48は既知の回帰目標で、新規な予測ではない。全行を保存する。
- EXP-008反例の同期二周期を再確認し、同一入力に対する非同期の全8!順序（40,320本）を直接計算して比較する。これはN=8の反例一件に限る全順列で、一般Nの全順列検査ではない。

## D — 判定と停止

全固定範囲を完走し、縮約予測・密行列表現・既存例の回帰・他型不変性が全て一致すれば `PASS`。一件でも不一致があれば最初の具体例を保存し `FAIL`。実行不能または上限到達で判定不能なら `UNCERTAIN`。成功を得るため探索範囲を延長しない。

## C — 対立仮説

同期二周期は特定seedや実装バグだけである。縮約が異型の反転を見落とす。ゼロ入力保持の境界alpha=6が誤っている。巡回順の割合を一様無作為順の確率と混同している。これらを別々に検査する。

## U — 不確かさと限界

標準ライブラリ・整数演算・固定列挙。丸め誤差はない。転記・実装・解析前提・列挙縮約の妥当性は別の誤差源。統計標本の標準誤差、合成標準不確かさ、包含係数は本検査では算出しない。有限検査の成功を全Nの証明とは呼ばず、一般の主張は別レポートで導出する。読者評価や創発生成の独立性を検証したことにもならない。

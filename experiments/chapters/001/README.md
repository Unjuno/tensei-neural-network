### 2. 用語

`terminology.md` で管理する。

第1回検証では1984年の日本語資料を最優先し、1987/1989年資料を近接時期の補助根拠として確認した。

主な結果:

- `連想記憶`: 1984年資料で直接確認 → 採用
- `手掛かり`: 1984年資料に「手掛かりパタン」 → 採用
- `想起`: 1984年資料に「想起過程（再構成過程）」 → 採用
- `神経回路網`: 1987/1989年資料で確認。本文では日本語主表記として採用し、初出ルビは読者補助とする
- `configuration`: 直訳語を使わず、`記憶パターン / 状態`へ変更
- `local field`: 人物語彙としての直接根拠が弱いため、`その素子に入る結合入力の総和`へ変更
- `asynchronous update`: ラベルを前面に出さず、`素子を一つずつ更新する`と操作を直接記述
- `fixed point`: `固定点《フィクスト・ポイント》`をやめ、近接資料にある`安定平衡点`へ変更
- `update order`: `更新する順番 / 更新順序`へ変更

これらは `novel/chapters/001.md` と `001-outline.md` へ反映済み。

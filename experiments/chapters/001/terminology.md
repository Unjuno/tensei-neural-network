## 判定状態

- `UNVERIFIED`: 候補表記。史料・時代適合を未確認
- `SUPPORTED`: 当時資料・近接時期資料から使用可能性を支持

- `REPLACE`: 本文から置換すべき
- `APPLIED`: 検証結果を本文へ反映済み

### S001 — 1984年「分布型連想記憶モデル」

- https://www.jstage.jst.go.jp/article/psychono/3/1/3_KJ00004405613/_pdf/-char/ja
- 1984年の日本語本文で `分布型連想記憶モデル`、`並列処理`、`ユニット`、`パタン`、`想起過程（再構成過程）`、`手掛かりパタン` 等を確認できる。
- 第1話のstory timeに最も近い資料なので、人物語彙の優先根拠とする。

### S002 — 1987年「神経回路網とスピングラス」

篠本滋「神経回路網とスピングラス」『物性研究』, 1987.

- http://hdl.handle.net/2433/92457
- `神経回路網`、`連想記憶モデル`、`局所平衡点`、`安定平衡点`、`パターン` 等を確認できる。
- 第1話候補時期より約2年後なので、1984–85年人物へ自動的に既知語彙として逆輸入しないが、当時近傍の日本語物理系語彙として参考にする。

### S003 — 1989年 甘利俊一「ニューラルネットワーク研究の過去，現在，将来」

- https://www.jstage.jst.go.jp/article/jjsai/4/2/4_120/_pdf
- `神経回路網`、`ニューラルネットワーク`、`線形閾値素子`、`結合の強度`、`連想記憶モデル`、`ダイナミックス` 等を確認できる。
- 1988年受理・1989年刊行なので、人物発話の直接根拠ではなく、1980年代末までに成立した日本語専門語の確認に使う。

## 今回の重要な修正

公開前本文では、英語専門語を日本語へ置換するだけでなく、**史料で弱い専門訳語は無理に出さない**。

具体的には、

```text
local field
→ その素子に入る結合入力の総和

asynchronous update
→ 素子を一つずつ更新する

fixed point
→ 安定平衡点 / もう一巡しても変わらない状態

configuration
→ 状態 / 記憶パターン
```

とする。

これは技術概念を削る変更ではない。操作・観測内容を日本語で直接記述し、必要な数学的厳密性はevent/experiment側へ保持する。

```text

```

を公開前に反復する。

## 残る不確実性

- 具体story dateが1984年か1985年か未確定なので、1986–89年に急速に定着した語を人物へどこまで許すかは未確定。
- `ハミング距離`については当時の日本語符号理論資料での直接確認を追加する余地がある。
- `素子`は日本語として自然だが、1984年のS001では「ユニット」が使われている。本文の可読性を優先して「素子」を採用するが、人物の専門的なノート表記まで固定したとはみなさない。

## 重要境界

- 当時人物が発話できる語と、現代読者向け地の文で使える語を同一視しない
- ルビのカタカナ原語が当時人物の実際の発話を意味するとは限らない
- 英語を減らすためだけに専門概念を誤訳しない
- 現代に定着した訳語を1980年代人物へ無検証で逆輸入しない
- 第1話で使わない語はここへ先回りして追加しない

# 第1話 話別実験 — EVT-004最小再現

状態: `PASS`

## 目的

第1話本文が依存する中心結果、すなわち

- 同一の初期状態
- 同一の三つの記憶パターン
- 同一の結合
- 同一の逐次更新規則
- 0入力時は現状態を保持

という条件で、**更新する順番だけを変えると、一方はA、もう一方はBへ到達する**ことを、第1話公開前の話別integration testとして再実行する。

これは新しい研究仮説を立てる `EXP-xxx` ではない。既存EVT-004の数理的主張を、章本文の公開前条件として再確認する実験である。

## 入力

```text
A = (-1, +1, +1, +1, -1, -1)
B = (+1, -1, +1, -1, -1, +1)
C = (-1, -1, -1, -1, +1, -1)

cue = (+1, -1, +1, +1, -1, -1)

order alpha = 1, 3, 6, 4, 5, 2
order beta  = 4, 6, 1, 3, 5, 2
```

結合は三つの記憶パターンの外積和から作り、対角成分は0とする。正の全体定数倍は符号判定を変えないため、正規化しない整数和を使う。

## 更新規則

各要素を指定順に一つずつ更新する。

要素 `i` へ入る結合入力の総和を `h_i` とすると、

```text
h_i > 0 -> +1
h_i < 0 -> -1
h_i = 0 -> 現在値を保持
```

一巡後に同じ順番でもう一巡し、状態が変化しなければその順番に対して安定と判定する。

## 事前合否条件

PASS:

- alphaがAへ到達する
- betaがBへ到達する
- A/B到達後、同じ順番でもう一巡して変化しない
- alphaとbetaで異なるのは更新順序だけである

FAIL:

上記のいずれかが再現しない。

UNCERTAIN:

実装条件がEVT-004と一致していることを確認できない場合。

```

2026-08-28の再実行:

```

両方とも到達後の次の一巡で変化なし。

判定: `PASS`

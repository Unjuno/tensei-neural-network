# Pilot Reader Study 001 — 第1〜4話

状態: `PREREGISTERED / WAITING FOR EXTERNAL READERS`

目的: AI編集simulationでは測れない、非専門読者の理解・読書ロス・人物への関心を小規模に観測する。

## Inclusion

- 18歳以上を想定
- 第1〜4話を今回の版で読む
- 研究ノート、EVT、verificationは先に見せない
- 同じ質問順を使う
- 都合のよい回答だけ採用しない

最低5人。5人未満では`UNCERTAIN / INSUFFICIENT_READERS`。

## 読了後質問

各話について:

1. この話で一番気になった問いは何だったか
2. 読む速度が落ちた場所はどこか。可能なら文・段落を特定
3. 分からなくても読み進められた箇所と、分からないため止まった箇所を分ける

4話読了後:

4. 高橋と佐伯の違いを、研究分野名を使わず説明してください
5. 「実際に観測したこと」と「人物がそこから考えたこと」の違いを一例挙げてください
6. 数学を完全に追えなくても第5話を読みたいですか。Yes/Noと理由
7. 次に起きる事件の予想ではなく、**どちらの人物の何をもっと知りたいか**
8. 小説ではなく研究解説を読んでいる感じが最も強かった箇所

## Predeclared interpretation

理解側の暫定PASS:

- 5人以上
- 少なくとも4人が人物の中心的な問いを大きく取り違えない
- 少なくとも4人が観測と解釈の違いを本文例で説明できる

文学側は単一PASSへ圧縮しない。

特に、

- 「理解できたが続きを読みたくない」
- 「数式は追えないが人物の続きを読みたい」

を別カテゴリとして記録する。

同じ重大な読書ロス箇所が2人以上で一致した場合は改稿候補。

## Bias controls

- 作者本人がその場で解説しない
- 「面白かったですか」だけで評価しない
- 読者の前知識を後から記録するが、結果を見て除外しない
- AIによるreader-loss auditの予測を読者へ見せない

## Result storage

個人を特定できる情報をrepoへ保存しない。

集計時は匿名ID `R01...` と回答要約、読了範囲、前知識カテゴリだけを保存する。

現時点では外部読者がいないため結果ファイルを作らない。
